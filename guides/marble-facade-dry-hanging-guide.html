雲石幕牆乾掛工程全攻略：系統、厚度、背網同驗收

首頁 › 石材攻略 › 雲石幕牆乾掛工程全攻略：系統、厚度、背網同驗收

雲石幕牆係高級商廈、酒店同豪宅外牆嘅經典做法，奢華又有氣場。但雲石天生軟身（莫氏硬度約 3、吸水率比麻石高），要掛上幾十層樓外牆又唔跌落、唔裂、唔變形，靠嘅就係「乾掛系統」同埋嚴謹工序。呢篇攻略幫你搞懂乾掛系統種類、板材厚度、背網加固，同最關鍵嘅驗收三寶：空鼓、平整度、縫寬。

雲石 Mohs 約 3比麻石軟，幕牆必須用乾掛唔可以濕貼
板材 25–30mm外牆乾掛厚度下限，大板要更厚
背網加固玻璃纖維網 + 樹脂，防運輸崩邊裂紋
驗收三寶空鼓、平整度、縫寬三大項不可省
重點速記

雲石幕牆千祈唔好濕貼上牆——水泥鹼水會滲入雲石、長期令佢發黃起粉。正確做法係乾掛：用不鏽鋼掛件將雲石固定在鋼龍骨，板同牆之間留空氣層。揀咩掛件、板有幾厚、有冇背網、驗收肯唔肯拍空鼓，直接決定呢幅幕牆用十年定用兩年就甩板。

點解雲石幕牆一定要用乾掛？

雲石係碳酸鈣，吸水率約 0.3–1%（視品種），表面有微細毛孔；如果用水泥砂漿濕貼上外牆，砂漿入面嘅鹼性水分會慢慢滲入石身，令雲石發黃、起白華、甚至粉化，而且濕貼受力唔平均，高樓風震下容易甩落。乾掛就解決晒呢啲問題：雲石板背後用金屬掛件鎖住，唔靠砂漿黏力；板同結構牆之間有 80–120mm 空氣層，通風防潮、容許熱脹冷縮，亦方便日後個別更換。所以香港正規雲石幕牆工程，全部係乾掛。

乾掛系統三種：插針、蝴蝶扣、背栓

常見乾掛系統有三類。第一，插針式（pin anchor）：喺雲石側邊鑽個淺孔，插住不鏽鋼針再掛上龍骨，工序簡單、成本低，但受力點細，適合矮樓或者室內背景牆，高樓外牆唔太建議。第二，蝴蝶扣 / 開槽式（channel / clip）：喺板邊開槽，用不鏽鋼扣片扣住，受力比插針平均，係香港商廈常用做法。第三，背栓式（undercut bolt）：喺板背鑽一個喇叭形倒錐孔，鎖入背栓，受力點喺板中央、完全唔傷板邊，抗震最好、最穩陣，高樓同大板首選，但人工同配件貴。三種都要用 304 或 316 不鏽鋼，避免生鏽染色。

板材厚度要求：幾厚才安全？

雲石外牆乾掛，板材厚度一般唔可以薄過 25mm，常見 25–30mm；如果係大尺寸（例如 1200×600mm 以上）或者高樓迎風位，要加到 30–35mm 甚至更厚，減低風載同自重在板中心造成嘅撓曲。厚度仲要平均，唔可以一邊厚一邊薄，否則掛上去會歪。恆生石材落單前會按樓高、板尺寸、風壓計算出建議厚度，避免「慳料慳出事」。順帶一提，雲石物料每平方呎約 $150–$600，視乎產地同品種，乾掛人工同龍骨另計約 $300–$800/呎。以上價錢只作參考，視乎規格與行情，以正式報價為準。

背網加固：雲石幕牆嘅保險

雲石軟，運輸同安裝過程最容易崩邊、暗裂。背網（back net）就係喺板背貼一層玻璃纖維網，再淋樹脂滲入石孔，等整塊板「連成一體」，抗撞擊同防裂能力大升。高品質工程仲會做雙背網或者用不鏽鋼細網，進一步加強。要注意：背網要用耐候、防潮嘅樹脂，唔可以貪平用會水解嘅膠，否則幾年後網脫落、雲石鬆散就大鑊。恆生石材每塊幕牆板出貨前都要過 68 道質檢，背網平整、無氣泡、無脫落係必查項。

防水、防潮同填縫

乾掛雖然留咗空氣層，但板縫依然係水同風入口。雲石幕牆要用耐候防霉填縫膠（通常係改性矽酮或者聚氨酯）填縫，唔好用普通玻璃膠，普通膠會老化發黑流水。填縫前板邊要做防水底，避免雨水沿板邊滲入空氣層積聚。香港多颱風多雨，幕牆仲要設計排水孔同防水披水板，讓萬一入水可以排走，唔可以積。背網、掛件、膠條全部要防潮防鏽，呢啲隱藏位先係幕牆壽命嘅關鍵。

驗收三寶：空鼓、平整度、縫寬

雲石幕牆完工，最緊要驗呢三項。第一，空鼓：用硬物（或空鼓錘）輕敲板面，聲音「啵啵」實淨就 OK，「㗎㗎」空洞就代表板同掛件唔貼、受力不良，必須拆返執。乾掛理論上唔似濕貼咁易空鼓，但掛件鎖得唔緊、背網脫咗都會有空鼓聲。第二，平整度：用 2 米直尺靠住板面，縫位高低差一般要 ≤ 2mm（高級工程要求 ≤ 1mm），否則日頭斜陽一照，波浪紋好醜。可以用拉線同水平儀全幅查。第三，縫寬：板縫要均勻，常見 6–10mm，誤差最好 ≤ 1mm；縫忽闊忽窄，整幅幕牆即刻顯得手工差。呢三項驗收，業主一定要現場同師傅一齊拍、一齊量，唔好簽收咗才發現。

香港天氣同高樓要點

香港颱風多、紫外線強、又有酸雨，雲石幕牆要額外小心。其一，迎風面同高層要用背栓式呢類抗震好嘅系統，龍骨要計足風壓；其二，雲石要事先做防護劑，減低吸水同酸雨蝕花；其三，深色雲石日曬會熱脹，留縫要比室內闊少少。仲有，幕牆頂部要設壓頂石同滴水線，防止雨水倒流入縫。呢啲都係香港師傅嘅實戰經驗，落單前問清楚。

日後保養同翻新

雲石幕牆唔可以當玻璃幕牆咁用清水機亂噴——高壓水會逼水入縫。建議每 1–2 年請專業用中性清潔劑同軟刷清洗，檢查填縫膠有冇老化、掛件有冇鬆。表面若失去光澤，可以安排吊船做晶面或者重新防護。發現單塊崩裂或變色，趁早換，避免擴散到鄰板。保養得法，雲石幕牆用十幾年都仲咁靚。

常見問題

雲石幕牆用咩乾掛系統好？

矮樓或室內背景牆可用插針式；香港商廈常用蝴蝶扣（開槽式），受力平均；高樓同大板首選背栓式，抗震最穩陣。三種都要用 304/316 不鏽鋼掛件，近海位用 316 防鏽。

幕牆雲石板要幾厚才穩陣？

外牆乾掛唔可以薄過 25mm，常見 25–30mm；大尺寸或高樓迎風位加到 30–35mm 甚至更厚，減低風載同撓曲。厚度要平均，落單前按樓高同風壓計。

背網加固係咪必需？

係。雲石軟，運輸安裝易崩邊暗裂，背網（玻璃纖維網 + 樹脂）令整塊板連成一體、防裂抗撞。高級工程做雙背網，樹脂要耐候防潮，唔可以貪平用會水解嘅膠。

驗收點樣拍空鼓？

用空鼓錘或硬物輕敲板面，實淨「啵啵」聲就正常；「㗎㗎」空洞聲即係板同掛件唔貼、受力不良，必須拆返執。每塊都要敲，唔好漏。

平整度同縫寬有咩標準？

用 2 米直尺靠板面，高低差一般 ≤ 2mm（高級 ≤ 1mm）；板縫 6–10mm、誤差 ≤ 1mm，要均勻。呢兩項日頭斜陽一照最易现醜，驗收時要拉線同水平儀全幅量。

雲石幕牆幾錢一方？

雲石物料每平方呎約 $150–$600，視乎產地同品種；乾掛人工、龍骨、背網另計約 $300–$800/呎。以上價錢只作參考，視乎規格與行情，以正式報價為準。
